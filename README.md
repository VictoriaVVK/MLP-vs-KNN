#  Car Classification using KNN and MLP

##  Description

This project classifies cars into **sport, family, or city** using two machine learning models:

* K-Nearest Neighbors (KNN)
* MLP Neural Network

It compares their performance and allows user input for predictions.

---

##  Features

* Load data from CSV
* Encode categorical features
* Train KNN and MLP models
* Compare accuracy
* Predict new car type
* Visualizations (confusion matrix, K analysis)



## Dataset

Features used:

* doors
* fuel
* engine_size
* weight
* car_type (target)


## Output

* Model accuracy
* Predictions (KNN vs MLP)
* Saved graphs (.png)
